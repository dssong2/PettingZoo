# UAM Toy Environment

This UAM (Urban Air Mobility) Toy Environment is a custom reinforcement learning environment built with Gymnasium and designed following PettingZoo-style multi-agent conventions. Default training in this environment is single agent but is built for multi-agent scalability. The drone must travel from one vertiport to another while avoiding collisions with obstacles, environment boundaries, and other drones if multi-agent.

Works with Stable-Baselines3 (PPO current training model) and supports experiment tracking with Weights & Biases.

Currently, this environment is contained in a forked repo from PettingZoo, installation details will be published soon.
